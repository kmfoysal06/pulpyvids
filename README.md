# Gutenberg video block
### Show better video player UI with the help of @videojs/react.

The block includes editor controls for choosing a poster image and configuring
the player controls, autoplay, loop, muted playback, inline playback, and
preloading behavior.

## Development

Use Bun for local development and builds:

```sh
bun install
bun run dev
bun run build
```
